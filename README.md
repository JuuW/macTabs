# iTabs

一个 macOS 菜单栏小工具:在屏幕顶部浮一条**浏览器式页签栏**,列出当前前台应用的所有窗口,点一下即可切换。支持的应用由你自己从系统已安装应用里勾选——Word、Excel、PowerPoint、预览,任何常开多窗口的 app 都行。

> iTabs 是 [SAP GUI Tabs](https://github.com/JuuW/SAPTabs) 的通用版:保留浮动页签栏的核心,去掉 SAP 专属的系统分组、事务码、TCode 收藏等功能,改成任意应用都能用。

## 功能特性

- **一条浮动页签栏** —— 常驻屏幕顶部、水平居中,仅在受支持的应用处于前台时自动显示,切到不支持的应用就隐藏,不打扰。
- **只列当前应用的窗口** —— 页签栏列出当前前台应用的所有窗口;切到另一个受支持应用,页签栏整体换成它的窗口列表。
- **应用图标 + 窗口标题** —— 每个页签显示该应用的图标和窗口标题,一眼看清是哪个窗口。
- **标题超长截断** —— 窗口标题超过设定长度时用 `…` 截断,长度可在设置里调(默认 20 字符,范围 5–100)。
- **单击秒切** —— 点页签立刻把对应窗口抬到最前,点击时不抢占焦点。
- **当前窗口高亮** —— 当前聚焦的窗口页签高亮显示;即便多个窗口标题相同也不会误高亮。
- **放不下自动收纳** —— 页签过多时,放不下的自动收进右端下拉菜单。
- **右键关闭** —— 在页签上右键即可关闭对应窗口。
- **极轻量** —— 原生 Swift + SwiftUI + AppKit,无后台服务、无网络请求,仅通过系统辅助功能 API 读取窗口信息。

## 环境要求

- macOS 13 (Ventura) 或更高版本
- 构建需要 Xcode 命令行工具(`xcode-select --install`),内含 Swift 工具链

## 安装

1. 克隆仓库并进入目录:

   ```bash
   git clone https://github.com/JuuW/macTabs.git iTabs
   cd iTabs
   ```

2. 运行打包脚本,会编译并生成可双击运行的 `iTabs.app`:

   ```bash
   ./build.sh
   ```

3. 把生成的 `iTabs.app` 拖进「应用程序」文件夹(可选),然后双击运行:

   ```bash
   open "iTabs.app"
   ```

> 应用没有经过 Apple 公证,首次打开若被 Gatekeeper 拦下,在「系统设置 → 隐私与安全性」里点「仍要打开」,或右键 .app → 打开。

## 首次运行:授权「辅助功能」

本工具靠系统辅助功能(Accessibility)API 读取和切换窗口,**必须授权才能工作**。

1. 首次运行时,页签栏会提示「需要辅助功能权限」,点「去授权」。
2. 在弹出的「系统设置 → 隐私与安全性 → 辅助功能」里,打开 **iTabs** 的开关。
3. 回到应用即开始正常工作。

## 使用

1. 点菜单栏的四色方块图标 → **设置…**,在列表里勾选你想支持的应用(可搜索),并按需调整「页签标题最大长度」。
2. 切到任一受支持的应用,页签栏会自动出现在屏幕顶部。
3. **单击**页签 → 切到对应窗口;**右键**页签 → 关闭该窗口。
4. 切到不受支持的应用时,页签栏自动隐藏;切回时再次出现。
5. 可从菜单手动停用「自动显示」。

配置保存在 `~/.itabs_settings.json`(受支持应用列表 + 标题截断长度)。

## 卸载

```bash
pkill -x iTabs
rm -rf "iTabs.app"
rm -f ~/.itabs_settings.json   # 如需一并清掉配置
```

退出应用后如需清理授权,在「系统设置 → 隐私与安全性 → 辅助功能」里移除 iTabs。

## 技术栈

Swift · SwiftUI · AppKit · Accessibility API(AXUIElement)。
